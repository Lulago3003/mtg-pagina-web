¿Cuánto cuesta la plataforma Medidor Inteligente?How much does the Medidor Inteligente platform cost? ▾
El costo incluye el sensor Emporia Vue 3, la instalación certificada y el acceso a la plataforma Medidor Inteligente. El precio varía según el número de circuitos y el tipo de propiedad. Contáctanos para una cotización personalizada — el primer análisis es gratuito.The cost includes the Emporia Vue 3 sensor, certified installation and access to the Medidor Inteligente platform. Price varies by number of circuits and property type. Contact us for a personalized quote — the first analysis is free.
¿Funciona con EDEMET, ENSA y EDECHI?Does it work with EDEMET, ENSA and EDECHI? ▾
Sí. Medidor Inteligente es compatible con las tres distribuidoras eléctricas de Panamá: EDEMET (Metro-Oeste), ENSA (Elektra Noreste) y EDECHI (Chiriquí). El sensor Emporia funciona con cualquier tablero eléctrico estándar de 120/240V.Yes. Medidor Inteligente is compatible with all three Panamanian electrical distributors: EDEMET (Metro-West), ENSA (Elektra Noreste) and EDECHI (Chiriquí). The Emporia sensor works with any standard 120/240V electrical panel.
¿Necesito Wi-Fi en mi propiedad?Do I need Wi-Fi at my property? ▾
Sí, el sensor Emporia Vue 3 requiere conexión Wi-Fi 2.4 GHz para transmitir los datos a la nube. Si tu propiedad no tiene Wi-Fi, podemos evaluar soluciones de conectividad alternativas. La señal puede llegar desde cualquier punto de la propiedad.Yes, the Emporia Vue 3 sensor requires a 2.4 GHz Wi-Fi connection to transmit data to the cloud. If your property doesn't have Wi-Fi, we can evaluate alternative connectivity solutions. The signal can reach from anywhere in the property.
¿Cuánto tiempo toma la instalación?How long does installation take? ▾
La instalación del sensor Emporia Vue 3 toma menos de 2 horas en la mayoría de las propiedades. No requiere un corte prolongado de energía. Nuestros técnicos certificados se encargan de todo — solo necesitas estar presente o designar a alguien de confianza.Installing the Emporia Vue 3 sensor takes less than 2 hours in most properties. It doesn't require extended power outage. Our certified technicians handle everything — you just need to be present or designate someone you trust.
¿Cuándo veo los primeros resultados?When do I see the first results? ▾

El primer reporte completo con recomendaciones específicas se genera a las 2-4 semanas, aunque muchos clientes ven ahorros desde el primer mes.From day 1 you have real-time data. With 7 days of history, Medidor Inteligente can start identifying patterns and anomalies. The first full report with specific recommendations is generated at 2-4 weeks, though many clients see savings from the first month.
